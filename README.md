# Backrooms Clark PAC

PAC3 model package and elongated Captain Clark outfit, prepared for HerrKvarkar.

The model and texture files come from the user-supplied extraction of Steam Workshop item [3749334160](https://steamcommunity.com/sharedfiles/filedetails/?id=3749334160), Backrooms Captain Clark Playermodel. They remain the property of their respective creators and rights holders. No ownership or new licence is claimed over those assets.

The ZIP uses the uncompressed Store method required by PAC3 and contains only model and material files, with no addon Lua.
